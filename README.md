# PHARMAGO

A web application to find pharmacies on duty in your area.

## Description

PHARMAGO helps users locate and get information about pharmacies that are currently on duty. The application provides real-time information about pharmacy locations, opening hours, and contact details.

## Fonctionnalités

- Localisation des pharmacies sur la carte
- Liste des pharmacies de garde
- Recherche par nom ou adresse
- Calcul des distances
- Itinéraires vers les pharmacies

### Prérequis
- Python 3.8+
- PostgreSQL

- React

- Axios
